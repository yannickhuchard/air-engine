# Vue de dossier AIR

Public : responsables métier, architectes et équipes de réalisation. Travail
principal : suivre une exigence jusqu’à sa réalisation prévue, puis comprendre
ce qui empêche sa réception.

Palette : bleu de structure #153653, bleu de lien #2457A6, fond #F2F6FA, papier
#FFFFFF, réserve #8A5800, blocage #A52839. Texte Segoe UI avec repli système ;
les références techniques restent dans les détails, pas dans le titre.

Disposition : un en-tête de dossier, un bandeau de réception, puis une chaîne
horizontale exigence/fonction/contrat/unité. Sous la chaîne, réception et inconnues
en pleine largeur, et registre des sources consultable par détails natifs.
Sur petit écran, la chaîne devient verticale. Alignement à gauche ; aucune
animation ni dépendance distante. Les cadres indiquent les étapes du modèle.

Revue de conception : éviter le tableau de bord à compteurs et cartes répétées.
L’information dominante est le lien de construction et son état de réception.
Les textes proviennent du modèle ; aucun faux bouton d’approbation. Impression,
navigation clavier, ancres stables et rendu sans JavaScript restent utilisables.
