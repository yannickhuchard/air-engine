# Direction du Workbench AIR

Public : architectes et contributeurs des équipes métier. Tâche dominante : ouvrir un contexte exact, retrouver l’objet concerné, comprendre ses liens et préparer une question attribuée.

Palette commune : structure #153653, lien #2457A6, fond #F2F6FA, surface #FFFFFF, réserve #8A5800, blocage #A52839. Typographie Segoe UI pour la lecture et les contrôles ; monospace uniquement dans le JSON technique replié. Aucun téléchargement de police.

Disposition : une barre compacte de contexte, puis deux panneaux. La colonne gauche conserve la recherche et la liste des objets ; le panneau principal présente l’objet sélectionné, ses propriétés lisibles et les objets reliés. Le formulaire de contribution s’ouvre à la demande dans ce panneau. Sur mobile, la liste précède le détail ; le bouton d’un objet conduit le focus au titre sélectionné.

Revue du brief : conserver la relation entre objets comme information dominante. Retirer les compteurs décoratifs, la grande bannière et les cartes répétées ; ce sont des outils de travail, pas une page promotionnelle. La distinction DRAFT et contexte historique accompagne les actions. Les liens ont le nom des objets ; URI et empreintes restent dans les détails techniques.

Clavier : contrôles natifs, focus visible, annonce du nombre de résultats et de la sélection. Pas d’animation ni de raccourci détournant la saisie. L’impression et un résumé sans JavaScript restent possibles. La préparation d’un JSON ne doit jamais être présentée comme un enregistrement dans AIR.
