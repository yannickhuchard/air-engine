# Ouverture publique AIR

Les sources courantes 0.35.0.dev1 sont publiées dans air-engine, avec licence
Apache-2.0, exemples Asteria, guides, tests et skills. L’historique privé et les
dossiers de travail restent séparés. Le plugin est distribué dans
[air-plugin](https://github.com/yannickhuchard/air-plugin).

La branche principale est une version de développement. La release rc9 reste
disponible et inchangée. Voir [validation](validation.md).
Une publication GitHub ne vaut pas approbation d’un plugin par OpenAI ou
Anthropic ; aucune nouvelle approbation d’annuaire n’est déclarée ici.
