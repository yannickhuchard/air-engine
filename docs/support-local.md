# Support du profil local AIR

Projet et développeur officiel : **Yannick Huchard**,
[dépôt AIR](https://github.com/yannickhuchard/air).

Le périmètre reçu par G1 est **0.34.0rc9 / Windows 11 / Python 3.12.14 / SQLite /
identité locale**, décrit dans [le périmètre publié](perimetre-local-supporte.md).
La branche **0.35.0.dev1** est une version de développement, sans réception de
production ni qualification native héritée automatiquement de rc9.

Le support est communautaire, au mieux des moyens disponibles : aucun SLA,
astreinte, durée LTS, délai de réponse ou délai de correction garanti. Une entreprise
ayant besoin de ces engagements doit les convenir séparément avant de s'y fier.
La compatibilité d'une nouvelle version se décide sur ses propres preuves ; une
version remplacée reste documentée dans le journal et les reçus historiques.

Pour un problème non sensible, ouvrir une
[issue sur le dépôt officiel](https://github.com/yannickhuchard/air/issues), avec
version, système, Python, code AIR, étapes de reproduction sur un dossier fictif,
résultat attendu et résultat constaté. Joindre uniquement des diagnostics expurgés.
Les conversations d'agent, bases, sauvegardes, jetons et journaux privés ne sont pas
des pièces publiques. Pour une vulnérabilité, suivre [SECURITY.md](../SECURITY.md) et
utiliser le canal privé approuvé avec le responsable de l'installation.

En cas de perte d'accès, arrêter l'exposition concernée, protéger les preuves,
révoquer les identités compromises puis appliquer la procédure de restauration
dans un nouveau home. Le [guide du poste](lot-poste-local.md) détaille ces gestes.
Le responsable local organise les copies de sauvegarde, leur protection et leurs
essais de restauration. Le projet ne conserve pas les données des entreprises.
