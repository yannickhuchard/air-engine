# Trois identités fictives

- `enterprise.json` : Asteria Industrie, marque du groupe, bleu pétrole et Arial.
- `consultant.json` : Morgan Conseil pour le client Boréal, ardoise, doré et Verdana/Georgia.
- `studio.json` : Atelier transformation, violet, Arial/Georgia, import de DESIGN.md.

Chaque fichier est une requête `branding-configure` et un artefact JSON réutilisable.
`DESIGN.md` expose les références de tokens et une valeur décorative non appliquée,
afin de vérifier sa conservation avec avertissement. Ces logos sont des formes
originales simples de démonstration, pas les marques de sociétés réelles.

Voir [le workflow CLI/MCP](../../docs/branding-dossiers.md).
